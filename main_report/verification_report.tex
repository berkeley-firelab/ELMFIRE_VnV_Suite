\section{How to Read This Guide}

Start with the verification summary for the aggregate-build environment,
case-declared execution configuration, and scientific decision table.  The
case identifiers in the summary link to the corresponding case-report entries.
The complete standalone reports follow in the stable numerical order defined
by \path{cases/Verification/CASE_REGISTRY.md}; each retains its own scientific
context, equations, metrics, citations, acceptance criteria, and limitations.

Interpret PASS and FAIL as the decision made by the case-local postprocessor
against that case's declared acceptance criteria.  A missing result, an unrun
or incomplete workflow, or an unsupported capability is shown as NOT
EVALUABLE.  Command completion and PDF availability alone do not establish a
scientific decision.

The aggregate-build environment describes how this guide was assembled; it is
not necessarily the execution environment of every included case.  Aggregating
the compiled PDFs keeps case-local macros, labels, bibliographies, and packages
isolated from one another.  After standalone reports change, rebuild this guide
with \texttt{make verification-report} or rebuild both suite reports with
\texttt{make reports}.

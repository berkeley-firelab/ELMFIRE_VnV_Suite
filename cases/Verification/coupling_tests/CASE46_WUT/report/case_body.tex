\section{Mathematical formulation and numerical implementation}

The intended WTU path deposits DFC and radiation from a burning wildland cell
onto an urban receiver, accumulates
\[
 Q_j(t+\Delta t)=Q_j(t)+[q''_{DFC,j}(t)+q''_{rad,j}(t)]\Delta t,
\]
and ignites after the fixed material threshold $F_{TP,crit}$ is met. Thus a
sufficiently heated target must have a finite delay
$\tau_{WTU}=t_{ign,target}-t_{ign,source}>0$. The same heat/FTP law then
produces urban ROS; no 30,000-kJ branch is part of this oracle.

As an optional implementation extension, for source \((i_s,j_s)\) and target \((i_t,j_t)\), the reviewed source condition
in \path{build/source/elmfire_spread_rate.f90:665-678} is
\[
 r=\sqrt{(i_t-i_s)^2+(j_t-j_s)^2},\qquad
 \mathcal I=(f_s\ne91)\land(f_t=91)\land(r\le1)
             \land(\FLIN_s>1000).
\]
The comparison is strict.  A true branch sets the target's WTU flag and skips
the ordinary DFC and radiation calculation for that target.  In both Runge--Kutta
stages, \path{build/source/elmfire_level_set.f90:2549-2595} forces its
\(\phi=-1\).  The newly burned-cell loop then records
\(\mathrm{TOA}=T\).  Initialization assigns every input \(\phi\le0\) source
cell TOA zero.

The FBFM01 source has five-percent dead one-hour moisture, zero wind, and zero
slope.  The input-design calculation uses
\[
 t_r=384/\sigma,\qquad \FLIN=t_r I_R R(0.3048),
\]
then searches adjacent IEEE-754 binary32 adjustment values so the reviewed
default-\texttt{REAL} operation order brackets 999, 1000, and 1001
\si{\kilo\watt\per\metre}.  This is only an input oracle; acceptance uses the
ELMFIRE \texttt{flin} raster.

The peer-reviewed WU--E publications describe interface heat transfer and
heat/FTP spread \cite{PurnomoPCI2024,PurnomoIJWF2024}. The supplied thesis supports
this scaling on PDF page 53 (printed page 31), equations (2.42)--(2.43), and
gives vegetation heat-release context on PDF page 64 (printed page 42),
equations (2.81)--(2.83). The intended equations are documented directly here.
Neither published source supplies the special 1000 \si{\kilo\watt\per\metre} branch,
selector linkage, forced \(\phi\), or dump-name oracle; those come exclusively
from the pinned source.

\section{Derivation of expected behavior}

For the primary oracle, positive DFC-plus-radiation must be observed at the
sufficient-heat adjacent and isolated receivers and ignition must occur after
a positive exposure delay. The initial-wildland-source HRR suppression is diagnostic, but later
propagation within the vegetative patch may create new heat-emitting sources.
The complete receiver history, not the initial-source state alone, determines
this observation.

For the optional shortcut, the contiguous variants request source FLIN of 999, 1000, and 1001
\si{\kilo\watt\per\metre} at an immediately adjacent FBFM91 band.  Only 1001
may transition.  Isolated targets test 999 and 1001 at one-cell distance and
1001 at two-cell distance; only the one-cell 1001 target may transition.  A
zero-adjustment target is the spontaneous-ignition control.  Thus the exact
boolean oracle is
\[
 (0,0,1)_{\rm contiguous},\qquad(0,1,0)_{\rm isolated},\qquad0_{\rm zero}.
\]

Both eligible transitions occur during the first update at \(T=0\): the heat
loop sets the WTU flag, both RK stages force the target negative, and the
newly-burned loop assigns TOA to the current solver time.  Since initial source
TOA is also zero, the exact expectation is
\[
 t_u=0\ \mathrm{s},\qquad t_s=0\ \mathrm{s},\qquad
 \tau_{WTU}=t_u-t_s=0\ \mathrm{s}.
\]
Every ineligible target must retain terminal \(\phi>0\) and nodata TOA.  The
evaluator requires \(\phi\le0\) and finite TOA to agree; either observable alone
cannot create an ignition result.

\section{Technical interpretation}

The current complete run fails the source-intensity setup check. The input
oracle specifies head-fire FLIN, whereas the terminal raster exports
surface-plus-canopy intensity from the initially burned-node list. That
export is not the same observation as the head-fire intensity assigned to the
WUI source list. A reliable threshold comparison requires a source diagnostic
that exposes the intensity actually consumed by the transition branch.

The receiver heat and positive-delay checks can still pass. Although the
initial wildland cells have suppressed transient HRR, the surrounding patch
can spread and create later heat-emitting cells. Positive receiver heat does
not therefore contradict initial-source suppression. Nor does a positive
arrival delay alone establish the complete intended accumulated-heat/FTP law.

The optional shortcut has a separate selector defect: the exposed namelist
value does not assign the integer tested by the branch. Its attribution rows
remain NOT EVALUABLE. The primary heat, delay, state, source-setup, and control
rows retain their own decisions; they are not all demoted because the optional
selector is unavailable.

\section{Scope and limitations}

This case covers one wildland fuel/moisture state, one cell size, a 60-s window,
contiguous and isolated targets, the strict intensity bracket, distance
boundary, state/timing update, and zero control.  It does not validate the
physical choice of 1000 \si{\kilo\watt\per\metre}, urban-to-wildland spread,
community propagation or convergence. Executable
path/hash/version prove that one binary produced all accepted outputs but do
not prove that binary was built from \SourceCommit; the commit remains the
documented implementation provenance. A source repair requires a newly reviewed,
content-bound PASS preflight before this unchanged strict matrix can yield a
shortcut-specific PASS or FAIL.

\section{Verification purpose}

\textbf{Case ID:} \texttt{\CaseID}. This case verifies two suppression pathways: stochastic initial attack across an ensemble and deterministic extended-attack containment during growth. The verification question is whether the initial containment fraction and extended-attack end time meet their independent targets.

\section{Mathematical formulation and numerical implementation}

Initial attack produces a Bernoulli containment outcome for each ensemble member; the estimator is \(\hat p=N_{\rm contained}/N\). Extended attack updates a suppression adjustment at interval \(\Delta t_{\rm EA}\), reducing spread until containment terminates the simulation. The final stop time is therefore an observable of the coupled suppression trajectory.

\section{Derivation of expected behavior}

The initial-attack configuration predicts containment fraction 0.54. The extended-attack reference end time is 88200 s. These references exercise different algorithms and are evaluated as separate required variants.

\section{Verification metrics and acceptance criteria}

The initial metric reads the complete fire-size statistics table and calculates the fraction with containment value at least 0.999; absolute tolerance is 0.05, large relative to expected sampling error but sensitive to algorithmic bias. The extended metric converts the reported stop time from hours to seconds and uses 15 percent relative tolerance to allow discrete hourly updates. Both variants must pass.

\section{Simulation configuration and predicted outcome}

The initial-attack variant uses an ensemble and writes fire-size statistics. The extended variant enables \texttt{ENABLE\_EXTENDED\_ATTACK} with 3600 s update interval on uniform Fuel Model 8. Both use local deterministic inputs; random-seed policy is stated in each namelist.

\section{Technical interpretation}

A fraction discrepancy implicates initial-attack probability or ensemble accounting; an end-time discrepancy implicates extended-attack updates, containment state, or time-unit conversion. No scientific conclusion should be drawn when the status is NOT RUN or NOT EVALUABLE.

\section{Scope and limitations}

The test verifies prescribed suppression algorithms in synthetic fires; it does not validate operational suppression effectiveness. This case provides implementation-verification evidence only.
